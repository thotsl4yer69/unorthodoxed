# UNORTHODOXED

Independent streetwear brand site — dark aesthetic, electric purple accent, distressed typography.

## Live

https://thotsl4yer69.github.io/unorthodoxed/

## Stack

Single-file static site. No build, no dependencies. HTML + CSS + small inline JS for scroll reveals and nav blur. Served via GitHub Pages.

## Sections

- Hero with glitch typography and large background lettering
- About + manifesto block
- Current drop (VOL.04) — 8-piece collection grid
- Lookbook editorial mosaic
- Drop calendar — live, upcoming, archived
- Contact + socials

## Local

Open `index.html` in any browser. No server required.
